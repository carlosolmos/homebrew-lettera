# homebrew-lettera

Homebrew tap for [Lettera](https://github.com/carlosolmos/lettera) — a typewriter-inspired journaling TUI.

## Install

```bash
brew tap carlosolmos/lettera
brew install lettera
```

Then run:

```bash
lettera
```

## Update

```bash
brew upgrade lettera
```

## Uninstall

```bash
brew uninstall lettera
brew untap carlosolmos/lettera
```
